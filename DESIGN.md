# Configuration interface

The configuration surface uses Impeccable's Operate mode: completing a mapping task takes priority over decoration.

- Sequence: choose a mode, resolve dependencies, edit hardware mappings, save.
- Use familiar native form controls and a restrained dark workspace, system fonts, one accent and semantic status colors defined as CSS tokens.
- Place original numbered hardware illustrations beside the selected control's editor. Supply equivalent text controls and keyboard navigation.
- Show only the selected mode's prerequisites and options. Explain missing dependencies beside their remedy.
- Keep loading, unavailable-input, unsaved, saving, saved and failed states explicit. Errors belong beside the affected field and in a live status region.
- Stack the workspace at narrow widths; preserve usable controls and focus indicators at 200% zoom. Avoid decorative animation and external fonts or assets.
