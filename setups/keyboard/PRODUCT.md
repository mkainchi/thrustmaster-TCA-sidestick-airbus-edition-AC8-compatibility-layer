# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Windows x64 gamers with a TCA Sidestick Airbus Edition and TCA Quadrant Eng 1&2. They clone or extract the project, configure controls and run emulation.

## Product Purpose

One offline page and two command entry points provide keyboard output through TARGET, direct Xbox emulation, and Xbox emulation through TARGET Combined.

Users must be able to identify controls, save independent mode profiles, resolve prerequisites, and start and stop a verified session.

Physical button presses select the matching device and binding while the editor is idle. The sidestick slider and quadrant's left lever share acceleration/braking; the last throttle moved beyond a small noise threshold takes control.

## Operating Context

Configuration runs on loopback; TARGET and system drivers are installed separately. Stick motion controls flight; the POV controls the camera. Editable ACE COMBAT examples must match the game's bindings.

## Capabilities and Constraints

- Plain HTML/CSS/JavaScript and Python.
- Explicit installed keyboard-layout choice; no French or English default.
- No telemetry, personal hardware inventory, automatic driver installation, bundled proprietary software or copied game assets.
- Offline original SVG device diagrams; manufacturer photos/manuals remain private comparison references.
- Only verified, licensed dependencies in releases.

## Evidence on Hand

Keyboard translation, editor protections, TARGET templates and Xbox mapping have automated software checks. Physical motion and gameplay need separate validation.

## Product Principles

Make mappings visible, preserve local choices, explain dependency remedies, release held controls on stop/input loss, and keep configuration and diagnostics private.

## Accessibility & Inclusion

Support keyboard operation, zoom and narrow windows. Label controls and expose errors/status to assistive technology.
